# H3 输出质检规范

## 通过条件

- 起始、中间、结束画面中的脸型和眼睛基本一致。
- 瞳孔、睫毛、头巾轮廓和发色没有明显漂移。
- 服装结构、主色、袖口、衣领和身体比例保持稳定。
- 动作中的手、手指、关节和衣物边缘没有明显错误。
- 角色没有被裁切，没有额外角色、文字、水印或复杂干扰物。
- 镜头没有突然切换或不可解释的背景变化。

## 丢弃条件

出现明显糊眼、瞳孔变形、换发色、换服装、肢体融合、重影、拖影或姿势断裂时，整条镜头丢弃，不靠后期修补后直接进入训练集。

## 抽帧原则

- 每段只保留少量代表性关键帧。
- 连续相邻帧只保留一张。
- H3 合成帧只能作为动作增广集；身份训练集仍以真实游戏素材为主体。
- 未通过人工对照的帧不能进入训练配置。

## 静音输出

本地 H3 工作流仍可能保留原生音频分支。需要静音文件时执行：

```powershell
ffmpeg -y -i input.mp4 -map 0:v:0 -an -c:v copy output_silent.mp4
```
