# H3 镜头生产规范

## 核心原则

H3 负责保持角色和场景参考，并生成单个镜头的自然运动。完整剧情不在一段长视频里完成，而是拆成短镜头后再剪辑。

## 参考图角色

每个 character manifest 自己定义参考图及 semantic role。`nun` 仅是仓库中的 example：

| 输入 | 作用 |
| --- | --- |
| `nun_primary.png` | 首帧构图、站姿和整体身份 |
| `nun_alternate.png` | 服装、头巾、发型和颜色补充 |
| `nun_face.png` | 眼睛、睫毛、眉毛、脸型和五官细节 |

H3 官方 Ref2VA 支持最多 9 张图片，但新增图片必须有明确作用；不要只为增加数量而堆叠相似或冲突素材。

## 两阶段参数

### 动作探索

- 约 0.5 MP
- 4 步 Turbo
- 4～6 秒
- 每个镜头 3～4 个种子
- 固定镜头或极轻微推近

### 质量保留

- 约 0.75 MP
- 8 步 Turbo
- 4～6 秒
- 只重跑已经通过动作和身份检查的种子

0.75 MP 不是 2K。H3 官方资料把默认基础输出和 2K 重生成分成两个阶段；当前本地工作流暂未接入 2K 重生成节点，因此不要把普通放大当作真实细节恢复。

## 提示词规则

- 使用官方 Ref2VA 六段结构。
- 所有参考标签在不同段落中保持同一含义。
- 每个镜头只描述一个主要动作和一个简单镜头行为。
- 明确禁止切镜、连续环绕、额外角色、复杂背景和文字水印。
- 为抽帧数据使用 `N/A` 声音策略；若本地节点仍输出音轨，后期用 FFmpeg 去除。

## 镜头拆分

推荐结构：

```text
镜头 1：睁眼或轻微表情变化
镜头 2：面部近景中的手部小动作
镜头 3：三分之二视角的姿态变化
镜头 4：武器或服装细节特写
```

不要让一个 10 秒镜头同时承担起身、转身、挥击、受击和剧情反应。
